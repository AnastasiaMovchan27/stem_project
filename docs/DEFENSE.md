## 2. Що показати (по кроках)
1. Відкрити `config.json`: пайплайни, спотворення, параметри (`config.json.пояснення.md` пояснює кожен ключ).
2. Термінал (демо в окрему папку, основні результати не чіпаємо): `python main.py --results results_demo run all --limit 5`, потім `python main.py --results results_demo compare`.
3. Відкрити `results/figures/examples_my_photo.png`: чисте / спотворене / P1 / P2 для твоєї фотографії.
4. Відкрити `results/tables/by_condition.csv`, `pairwise.csv`, `ablation.csv`, `scenarios_check.csv`.
5. Запустити тести: `python -m unittest discover -s tests -t .` (має бути OK).

## 4. Питання й відповіді
**Чим відрізняються два пайплайни?** P1 = фільтрація → гістограма → ретушування; P2 = ретушування → Фур'є →
фільтрація → яскравість/контраст. Категорії різні, разом їх п'ять (`src/stages.py`, словник `CATEGORIES`).

**Що робить білатеральний фільтр?** Усереднює сусідів з вагою за відстанню й за схожістю яскравості:
`weights = space * np.exp(-((window - arr[i, j]) ** 2) / range_denominator)`. Сусід з іншого боку краю має іншу
яскравість, вага майже 0, тому край не розмивається. Малий `sigma_range` — майже нічого не усереднюється,
великий — звичайне розмиття.

**Чому P2 краще при імпульсах?** `impulse_inpaint` знаходить саме пікселі 0 і 255 і міняє тільки їх середнім
чистих сусідів, а білатеральний фільтр сприймає імпульс як край і не прибирає його.

**Як працює CLAHE?** Плитки 8×8, у кожній гістограма обрізається на `clip_limit` × середню висоту, надлишок
розподіляється порівну, накопичена гістограма дає таблицю; піксель беремо з 4 найближчих таблиць білінійно
(`tile_table`, `clahe`). Чому `range_threshold`: корекція потрібна лише слабоконтрастним зображенням.

**Що таке PSNR і SSIM?** PSNR = 10·lg(255²/MSE), дБ, більше — краще. SSIM порівнює середні, дисперсії й
коваріацію в вікнах 8×8 з кроком 4, 1 — ідентичні. Чому два: PSNR — похибка пікселів, SSIM — структура.

**Як працює фільтр Вінера в частотній області?** Оцінюю σ шуму (Immerkaer), ДПФ рахую вручну як `W·f·W`,
кожен коефіцієнт множу на G = max(|F|² − s·σ²·N, 0)/|F|²: слабкі за шум частоти зникають, сильні лишаються.

**Як оцінюється рівень шуму?** Маска [[1,-2,1],[-2,4,-2],[1,-2,1]] прибирає плавні зміни й лишає шум;
σ = sqrt(π/2)/(6(W−2)(H−2))·Σ|згортка|.

**Що таке дифузія Переона–Маліка?** Згладжування по ітераціях, де провідність c(g)=1/(1+(g/κ)²) падає на
сильних перепадах, тож краї зберігаються. Рядок: `conductance = 1.0 / (1.0 + (diff / kappa) ** 2)`.

**Чому деякі стадії погіршують результат?** Див. `results/tables/ablation.csv`: нерізке маскування підсилює
залишки шуму, розтягування контрасту шкодить на природно малоконтрастних знімках, дифузія після видалення
імпульсів розмиває деталі. Тому в них є пороги.

**Як гарантується відтворюваність?** Генератор `np.random.default_rng([seed, crc32(знімок), crc32(спотворення)])`
(`src/degrade.py`, `make_rng`): однаковий шум при кожному запуску й не залежить від порядку обробки.

**Навіщо контрольні зображення?** Кожне 20-те зображення (`held_out_names`) використано для підбору параметрів і
виключено з аналізу, щоб не підганяти параметри під ті самі дані.

**Яка статистика порівняння пайплайнів?** Парна різниця PSNR на тих самих зображеннях, середнє, 95 %
інтервал = 1,96·s/√n (`comparison.paired_comparison`). Якщо інтервал не містить 0, різниця значуща.

**Які обмеження роботи?** Синтетичний шум, підбір за PSNR, зменшення до 128×128, детекція імпульсів лише за
значеннями 0/255, оптимум параметрів пологий (різниці до 0,1 дБ).

**Чому код не повторює лаби 5–6?** Там були усереднення, Гаусс, медіана, мін, макс, середина діапазону;
тут інші алгоритми (білатеральний, дифузія, CLAHE, ДПФ тощо).

**Як додати нову стадію?** Три місця: функція в модулі, гілка в `stages.run_stage`, запис у `CATEGORIES` і назва
в списку пайплайна в `config.json`.

## 5. Типові зміни коду на захисті
* **Змінити параметр:** у `config.json` → `"stages"` → `"bilateral"` → `"sigma_range": 25`; запуск
  `python main.py --results results_demo run pipeline1 --limit 5`, потім `python main.py --results results_demo compare`.
* **Нове спотворення:** `"sp_10": {"type": "salt_pepper", "prob": 0.1}` у `degradations`; `degrade`, `run all`.
* **Нова стадія «негатив»:** у `src/histogram.py` функція `def invert(image): return 255.0 - image`; у `src/stages.py`
  гілка `if name == "invert": return histogram.invert(image)` і `"invert": "Регулювання яскравості та контрасту"`
  у `CATEGORIES`; назва `"invert"` у списку пайплайна.
* **Інша метрика (наприклад, MAE):** функція в `src/metrics.py`, додати ключ у `compare` (і в `ROW_FIELDS`,
  `process_job`, якщо потрібно в таблиці).
* **Інше вікно:** `radius` у `bilateral` (вікно = 2·radius+1) або `max_window` в `inpaint`.

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
python main.py prepare && python main.py degrade && python main.py run all
python main.py compare && python main.py analyze && python main.py check && python main.py plots
```
